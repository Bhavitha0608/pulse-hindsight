# 90-second demo

1. Click **Load support history**.
2. Open Support Console.
3. Say: “A normal support bot sees one ticket. Pulse sees the customer's history.”
4. Click **Investigate with Pulse + Hindsight**.
5. Point out that prior troubleshooting is recalled and the agent avoids repeating failed steps.
6. Open Emerging Issues and click **Detect emerging payment issue**.
7. Say: “Now the memory scales from one customer to an organizational signal.”
8. Open Hindsight Memory to show the actual retained memories.
9. Close: “Pulse turns support history into operational intelligence. The longer it runs, the more useful its memory becomes.”
